## Linux: Phantom Recording Fix

If Handy on Linux sometimes started recording on its own, or cut off a real
dictation mid-sentence (typically about 2 minutes in), that was a signal
conflict: Handy listened for `SIGUSR1` as a remote-control trigger, but
WebKitGTK — the webview engine embedded in Handy — uses the same signal
internally for JavaScript garbage collection. Every GC cycle looked like a
hotkey press ([#1660](https://github.com/cjpais/Handy/issues/1660)).

Handy no longer listens for `SIGUSR1` on Linux.

**If you bound `pkill -USR1 -n handy` to a hotkey, replace it with:**

```bash
handy --toggle-post-process
```

`SIGUSR2` (plain transcription toggle) is unchanged and keeps working.

## Dynamic Island overlay

The macOS recording overlay now hugs the camera housing and matches the
notch's safe-area height. Listening, live transcription, finalizing, and
cancellation states have clearer spacing and remain readable while text is
streaming.

## Selected-text translation

Selected-text translation now captures the selection reliably, shows its own
translation target, and presents progress and results in a dedicated overlay.
The shortcut path also avoids conflicting with the normal transcription
shortcut while copying selected text.

## Build and release reliability

The fork build pipeline now produces unsigned Windows x64, macOS Apple Silicon,
and macOS Intel artifacts. Release signing remains reserved for configured
production credentials.
