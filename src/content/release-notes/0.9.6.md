## Fork update channel

Handy now checks only the Arunstha21/Handy release channel for updates. It no
longer follows the upstream cjpais/Handy release feed.

The fork release workflow signs updater packages with a dedicated Tauri updater
key, so platform certificates are not required to deliver signed in-app
updates.

## Certificate-free installation

The macOS build is ad-hoc signed. On first launch, use Control-click (or
right-click) the app, choose **Open**, and confirm **Open** in the dialog. If
macOS still reports that the app is damaged, install it in `/Applications/`
and run:

```sh
xattr -dr com.apple.quarantine /Applications/Handy.app
open /Applications/Handy.app
```

A Developer ID certificate and notarization are still required for completely
silent Gatekeeper approval.

Windows builds are usable without a certificate; if SmartScreen appears,
choose **More info** and then **Run anyway** after verifying the download came
from this release page.
